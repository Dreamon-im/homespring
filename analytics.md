# Analytics

This is a personal tool with no user metrics. What's tracked below are reliability metrics.

## Metrics to track

- Number of writes to a real device, and the share that came back `verified: true`
- Rejected writes, counted separately by cause: hash mismatch, over capacity, widget position would change
- Per reorganization, the number of `iconctl` calls and the number of writes
